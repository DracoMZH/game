# ПЕРЕПИСЬ

Текстовая игра-новелла о мире, который существует, только пока его учитывают.

Реальность здесь ведётся, как бухгалтерская книга: всё, что вписано в Реестр, существует; всё вычеркнутое — истончается. Чернила делают из забвения: чтобы вписать что-то в мир, Учётчик отдаёт собственное воспоминание. А где-то внизу сидит тот, кто читает Реестр — и никто не видел его в лицо.

Ты — Векша, Учётчик второго круга, вырвавший из Реестра страницу собственного брата. Теперь брат отвязан от мира и стирает город тем, что дышит. У тебя есть одна ночь, страница за пазухой и три плохих варианта.

## Как играть

Никакой сборки не нужно — это чистый HTML/CSS/JS:

```bash
# вариант 1: просто открыть файл
open index.html

# вариант 2: локальный сервер
python3 -m http.server 8000
# → http://localhost:8000
```

Прогресс сохраняется в localStorage автоматически.

## Механики

- **Память как ресурс.** Некоторые пути требуют отдать воспоминание — навсегда. Потраченное влияет на сцены (забыл свист брата — не сможешь его позвать) и на эпилог.
- **Истончение мира.** Пока ты медлишь, город выцветает. Шкала растёт с каждым действием; на 100 — город соскальзывает, и это тоже концовка.
- **Своя воля NPC.** Имрель может отказаться от спасения. Грай распознаёт ложь. Ладна готова заплатить за тебя — если ты ей позволишь.
- **Предупреждения о ловушках.** Игра честно помечает опасные выборы знаком ⚠ — но не запрещает их.
- **9 концовок**, включая одну тайную, которая открывается только знанием, добытым в другой ветке.

## Структура

```
index.html      — каркас интерфейса
css/style.css   — оформление («чернила и бумага»)
js/scenes.js    — сценарий: сцены, выборы, цены, концовки
js/engine.js    — движок: состояние, рендер, сохранение
```

Чтобы добавить сцену, допишите объект в `SCENES` в `js/scenes.js` — движок подхватит её сам.
